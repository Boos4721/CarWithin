# 整合体验真机验收（Build 23）

本轮包含首页折叠、BMS 卡片自定义、车辆配置、自动全屏、连接诊断及电池统计。单元测试和 Xcode 构建不代替下面的 UI、蓝牙与仪表验收。

## 首页与卡片

- 先等待有效视频画面：仅收到参数集时不提前折叠；画面被接收层接受后，首页收起说明、把画面/操作栏移到状态卡下面。点击连接详情可展开，停止后恢复准备界面；仪表状态仍可查看。
- 手机纵横屏、全屏退出、切后台再返回，检查状态/停止按钮、视频比例和触控。字号较大的系统文字不能盖住按钮。
- 在「电池与 BMS → 卡片显示」逐项开关六个字段，最后一项不能被关闭。精简布局显示电量、总压和压差；常用布局显示六项。最多两行，字号三档在手机及五寸/七寸远端均改变实际尺寸。
- 修改无需重启 CarPlay 或 BMS。重开 App 后选择保留；旧版默认仍为中号六项。无传感器值显示 --，断线后卡片不得显示旧数值；告警提示不随字段开关消失。
- 在设置开启出画后自动全屏，确认进入与退出；关闭后 iPhone 保留内嵌画面。iPad 保持原有自动全屏。

## 车辆配置

- 配置一辆五寸车和一辆七寸车，各保存不同 SSID、仪表地址、BMS 和字号。停止连接后切换，检查恢复对应设备和显示设置，密码仅从所选 SSID 的 Keychain 获取。
- 更改当前车辆的卡片设置或退出设置后，配置自动更新；切换前也更新当前车辆。未选择车辆时仍可直接使用原设置。
- 连接/等待 Wi-Fi 时禁止切换；删除当前车辆只取消配置选择，保留现有连接设置和 Wi-Fi 密码。
- 故意未填写/填错 Wi-Fi，不得把不完整字段覆盖到已保存车辆；重新签名导致 Keychain 无密码时需在 Wi-Fi 页补全。

## 诊断报告

- 成功启动后核对 Wi-Fi、配件、控制、首个关键帧和仪表通道事件。首帧时间以关键帧为准；仪表应答不代表已激活投屏。
- 错误 Wi-Fi 配置、iAP2 超时、接收器失败分别记录失败信息；停止清理不能覆盖终态失败。自动重连保留同一时间线。
- 重复状态不应无限堆积，最多保留 64 个事件；重启可查看上次记录。预览中的 JSON 与复制/分享内容应一致，包含 App/iOS 版本，不包含 Wi-Fi 密码或身份私钥。

## BMS 记录

- 开启 BMS 并启动 CarPlay 后开始记录；也可单独手动开始。开始之前缓存的旧样本不能计入新记录。
- 同一 BLE 帧重复回调不重复计数，过期或倒退的时间不计入。断开一段时间再重连，间隔不计入有效采样时长，趋势跨断线不连线。
- 核对电量起止值、电压最小/最大值、带符号电流和功率的绝对值峰值、最高温度及最大压差。缺失温度和单体值保持未知。
- 每 15 秒保存同一记录的片段，不能形成重复历史；结束后变为完整记录。最多 20 次，每次趋势最多 120 点；整体极值不受趋势窗口裁剪影响。
- 切换 BMS 或车辆、停止 CarPlay、关闭 BMS 时完成旧记录，不混合两台电池。强制终止 App 后可查看最后检查点，标为保存片段。
- 历史可读摘要、查看电压趋势、预览/分享 JSON、删除；导出不触发网络上传。无车速/距离数据时不显示每公里耗电或续航估算。

## 当前限制

九号独立激活仍需要分析官方开启投屏时的真实通信；Build 23 没有实现替代该流程。需要九号出行激活的仪表仍按原流程操作。五寸和七寸必须分别验收。
