# Build 30 / 极核 5 寸统一入口

开发分支 codex/ninebot-ant-bms。输出列表将原 SE+ 与 AE2 Pro 两项合为「极核 5 寸」，继续使用编号 8。设置 → 输出设置 → 仪表型号可选 SE+ 或 AE2 Pro。

## 行为

- 根据所选型号使用原来的协商路径：SE+ 的通知应答、横屏偶数尺寸、25/30/60 FPS、兼容/全宽画布与直传实验选项；AE2 Pro 的上报尺寸（包含竖屏）、奇数向下取偶和 25 FPS 兼容转码。
- 现有手动地址、自动发现开关仍按型号独立保留。6.2 寸维持独立输出，九号编号与协议不变。
- 旧全局输出 9 自动变为 8，型号为 AE2 Pro；旧输出 8 默认 SE+。重复迁移不覆盖用户之后选定的型号。
- 车辆预设增加可选 zeehoFiveVariant。旧 AE2 预设转换为输出 8 / 型号 1，SE+ 为输出 8 / 型号 0，保留车辆 UUID、地址、Wi-Fi、BMS 与视频设置。切换车辆时先恢复型号，再恢复对应地址和参数。
- 用户改选型号后立即保存并刷新相应设置；连接期间禁止更改。

## 验证

保留 6.2 代码哈希核查、尺寸/压缩帧/控制应答/TCP 媒体测试，增加统一入口的型号映射与协议规则隔离、车辆及临时 UserDefaults 迁移检查（旧编号 8/9、重复迁移、0–7 不变、独立参数保留）。完整核心测试和 iPhone/iPad Release 编译，不使用 iOS 模拟器。

GitHub PR #39 在本次核对时 head 为 9322cfc00e66c7ade668dab3d7afcb41f6c6f26d，已在开发分支；API 和远程 ref 均尚未返回新整合提交。本改动在现有 #35 / #39 合并版本上统一产品入口，不声称已取得更新的上游版本。

仍需实际仪表验证型号选择、前后台恢复和长时间输出；入口合并不会证明实验性直传或持续 60 FPS 已兼容。
