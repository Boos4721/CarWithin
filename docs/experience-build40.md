# 车辆连接概览、电池概览与结束摘要 / Build 40

## 首页

车辆配置、Wi-Fi、本机 CarPlay、仪表／输出和 BMS 状态集中呈现。点击各行进入相关设置。连接期间禁用车辆切换。详细的仪表说明和连接设置通过「连接详情」展开；出画后仍沿用紧凑模式和可选自动全屏。

Wi-Fi 只在系统返回当前 SSID 且存在 Wi-Fi 地址时显示该网络已连接；名称未知则明确提示未确认，不把已保存预设当作实际连接。路径变化会清除名称缓存，并忽略旧异步查询结果。

CarPlay 出画来自实际本机显示层接受画面。九号新增明确通道阶段回调：端口占用、通道就绪、仪表回应、发送、恢复、失败。UI 不解析日志判断这些阶段，发送视频始终保留仪表出画待确认。没有新增激活指令。

## 电池

电池状态、主要读数、电池状态参数和本次记录分别分组。主要读数为电量、总压、电流、功率；温度、压差与最高／最低单体另列。根据同一设备／协议变体的有效字段能力展示，小哈仅显示广播电量；临时缺失不缩减已确认的字段，过期数据清空为 --。

设备管理支持电池显示名称，按蓝牙 UUID 本地保存，清空恢复原设备名。不修改 BMS 广播名、配对身份或记录归属。

## 结束摘要

结束含有效样本的记录后保留摘要快照，包括记录时长、电量起止、覆盖率及实际提供的全程电压、峰值绝对功率、最大压差、最高温度。首页仅在停止且车辆归属匹配时显示；无样本不产生新摘要。进入记录详情仍可查看和导出完整记录。

「结束后自动打开摘要」默认关闭。开启后仅用户结束连接或记录时尝试打开，自动重连不显示结束卡片，设备切换和后台停止不弹出页面；已有其他模态界面时不抢占。摘要快照保留在本次 App 运行期间，持久记录仍在历史记录中。

不增加 Wh/Ah、估算续航或通用告警阈值，不改变各协议现有电流符号。

## 验证

增加网络确认与本机／仪表状态边界测试，以及电池字段、广播记录、空记录、真实零值、全程范围和完整度摘要测试。运行现有 BMS、核心协议、UDP、车辆迁移及输出协议检查，并编译 generic iphoneos arm64 Release，不使用模拟器。实际字体、单手操作和车辆连接仍需真机检验。
