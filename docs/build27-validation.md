# Build 27 / 九号观察插件 0.2

## 触发与证据

用户提供 iPadOS 16.6、九号出行 6.10.13（3858）的诊断面板，录制与停止入口已挂钩，手动开启官方投屏后图像转换仍为 0。注入日志显示 dylib 已复制、hermes 已修改并重签，最后保存 PersistentPlugins 副本时目标目录不存在。截图确认运行时加载；不能把持久化副本失败或 LC_CODE_SIGNATURE 工具提示当作当前未注入的证明。

## 修正

- 旧版只观察普通 CGImage 转换，面板只展示录制/停止挂钩状态，打开后又是静态快照，无法区分未匹配、未调用、空输出、另一视频路径。
- 新增普通/MJPEG 的类方法和实例方法观察、编码后回调观察，全部严格核对方法类型，转发原实现，不读取视频载荷或主动调用车辆指令。
- 面板区分挂钩状态和调用次数，每 0.5 秒更新，离开后释放定时器。标记按钮明确带「标记」前缀。
- JSON 增加可选版本、分项计数、匹配状态/类型签名、最多 32 条相关方法清单。保留 schema 1 和原五个 hooks 键，Build 26 仍可读旧字段；Build 27 可验证并完整保留新增字段。
- 本插件不尝试修复 TrollFools 全局持久化目录；该错误需在注入器/有相应访问能力的文件管理工具中处理。

## 检查

完整核心测试新增路径分项、旧报告兼容、可选字段边界与“编码回调不能证明仪表已激活”的验证。原有 IPA 准备工具测试继续执行。Mac 原生 Objective-C smoke 复用插件 runtime helper，检查方法类型、子类挂钩不修改父类、原方法转发参数和次数。iOS Release 和插件 arm64 编译，不运行模拟器。

## 真机回归

结束九号，在 TrollFools 移除旧本插件记录再注入 0.2，重新启动后面板必须显示插件 0.2。开始新采集，手动开启官方投屏，观察录制、普通、MJPEG、编码回调各自状态与次数，再标记实际仪表出画并导出 JSON。保持面板打开时持续产生的回调应反映到计数，关闭面板不保留刷新 timer。无法命中的方法需在 JSON 中看到缺少类/方法或类型不匹配。若全部调用仍为 0，用方法清单继续定位 6.10.13 路径，不能据此宣称仪表未激活或修改版不能投屏。
