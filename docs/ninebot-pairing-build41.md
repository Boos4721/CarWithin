# 九号车辆配对体验 / Build 41

## 操作流程

车辆配对页优先显示当前阶段、目标车辆和进度条，完整步骤可展开，减少扫描结果与确认按钮在小屏上的滚动距离；配对进度拆分为选择车辆、连接准备、P 键确认、认证保存、完成。首次用户主动发送配对请求后，显示 60 秒确认倒计时。已有密钥通过认证时，P 键步骤显示沿用已存配对，不声称用户已按 P 键。

认证及 Keychain 保存成功后显示成功区域；连接实际断开后可选择「用于当前车辆」。保存新车或检查另一台已配对车辆不会自动替换原选择。选择仍通过原回调保存到当前车辆配置。

## 扫描与恢复

每轮扫描最多 30 秒，显示倒计时和设备数，取消／选车／蓝牙中断均取消旧扫描截止任务。扫描轮次标识阻止旧截止回调结束新一轮扫描。

显示设备名称、本机 UUID 后六位、信号强弱、广播协议状态及已有配对标记。已配对设备置前，其余维持本轮发现顺序，不随 RSSI 波动跳动。只显示通过九号广播校验的设备，不凭名称或通用 UART 服务放行。

超过 10 秒未收到广播的设备不可直接选择；UI 计时与连接入口分别检查有效期，点击时使用缓存中的最新设备记录。重新扫描后需再次验证广播。信号强弱只是提示，不自动选车。

连接失败可显式重试上一台车；正在断开旧连接时提示等待，不提前用同一 CBPeripheral 建立重叠连接。蓝牙关闭或权限不足时提供系统设置入口。离开页面继续沿用取消配对规则。

## 已配对车辆

「检查蓝牙连接」只走原认证握手，不请求导航开启，不自动写入新的配对密钥。车辆要求配对时仍停在需要人工操作的步骤。配对写入仍需用户点击请求并在车辆确认；原始广播名继续用于加密身份，没有改名或猜测协议。

删除前确认只清除本机车辆记录和密钥，不声称解绑官方账号。多按钮行使用独立按钮样式，避免选择车辆和检查连接同时触发。

## 验证

新增 8 项测试：扫描／确认窗口边界、异常时钟、过期广播、未知 RSSI、完成状态依据、投屏与配对阶段分离、身份检查的指令权限及同名车辆选择保持。保留现有广播分包、加密、重放、密钥候选、导航意图和车辆迁移检查。

运行 native macOS 核心测试和 generic iphoneos arm64 Release 构建，不使用模拟器。真实车辆扫描、P 键确认、密钥认证及仪表投屏仍需用户实车验证。
