# 电池卡片显示第一轮优化 / Build 52

## 行为

- 新增“大字卡片”样式：第一项作为大字主值，品牌／状态使用小标题，其他字段独立排列，避免整行一起压缩；保留“经典两行”。既有配置缺少新字段时继续采用经典样式。
- 三个手动预设：骑行简洁（电量、总压、功率）、电池监测（电量、总压、最高温度、压差）、充电（电量、电流、功率、最高温度）。选择后切为自定义与大字样式，内容固定；读数变化不会自动切换预设。字段排序可调整主值。
- 设置预览可拖动，松手保存。位置按卡片在可用区域中的相对行程保存为 0–1，不绑定某个仪表分辨率。四角吸附、上下左右微调和 VoiceOver 自定义操作提供替代入口。
- 使用共享几何函数计算手机、预览、九号与极核位置，保留画面边距；卡片过高时等比缩小。Core Image 输出将顶部坐标转换为底部坐标；真实纵向尺寸预览不再压成正方形。
- 无实时数据时缩为一行“电池 · 无实时数据”，也可选择隐藏；收到有效数据后恢复。旧值仍按原规则清空，手机详情保留原因与更新时间。
- 样式、失联选项、自定义位置以可选字段存入车辆配置，兼容旧记录。切换快捷字段只替换字段内容，保留位置和样式。
- 新绘制路径使用 CoreGraphics／CoreText，生产渲染可直接在原生 macOS 验证；示例读数仅用于设置和测试，不进入实时投屏或记录。

## 验证

新增 6 项核心测试覆盖旧配置默认、新值边界、预设稳定、主值排序、各分辨率和长卡片边界、位置恢复。原有车辆迁移冒烟检查增加新字段与旧 schema 往返验证。

新增 4 组原生生产渲染检查：经典尺寸、三个预设与多仪表画布、未知字段／失联与恢复、真实 Core Image 自定义位置。CI 保存经典、新预设、4.3 寸合成及失联 PNG 供人工检查。其他核心、BMS、九号配对、九号／极核输出和身份打包验证继续保留，最终编译 generic iphoneos arm64 Release，不使用模拟器。

字段级阈值提醒、联动曲线、双设备连接和新遥测字段仍属后续范围。本轮继续显示已有设备告警；未新增通用温度或压差安全阈值。
