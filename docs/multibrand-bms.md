# 多品牌 BMS 只读接入 / Build 33

参考 lswlc33/maibms 的「支持的保护板」，固定提交 `6bbb5d64ef823385df5f5b8dd54580594a604ba5`。Swift 协议为 maibms 的只读移植，MIT 通知保留在 LICENSES/maibms-MIT.txt 并打包在本地应用。没有复制第三方厂商 App 或其凭据。

## 范围

| 板型 | 当前实现 |
| --- | --- |
| 蚂蚁 ANT | 原有 7EA1/C1 实时读取、CRC16、FFE0/FFE1、卡片和记录继续兼容。 |
| 彦阳 YYBMS | B 代 Profile/Summary/Status FC03 读取；默认地址 1，失败后一次地址发现；旧 A 独立基础/扩展读取。仅显示有依据的旧 A 电压、单体、普通变体温度，电流原始值放详情，SOC/容量/方向不猜测。支持 FFE2/FFE1、FFE1 同特征和两种 FEE9 模块。 |
| 极空 JK | 97 设备信息和 96 实时读取；校验 300 字节帧，根据实际结构及软件版本区分 JK02 24S/32S 和 JK04。JK04 只显示有效单体之和、均衡与运行秒数，不填充电流/SOC/容量。 |
| 蓝宝电量计 | FFE2/FFE1 的 FA50 双表及私有 CRC，保留出厂电流符号；显示电量、压差、已返回的设备/中继信息。没有逐串网格、MOS 或 SOH。可填写自己的匹配码，空值使用协议定义的默认匹配码。 |
| 陆行 EM2APP / EM02 | Build 45 新增：FFE0/FFE2/FFE1，四块 FC03 只读、自测总压、原厂方向电流/功率、SOC、最多 30 串、温度及中继信息；SOC × 额定容量为计算剩余容量。请求/应答 CRC16 校验，辅助块不刷新实时读数。 |
| 嘉佰达 JBD | FF00 FF02/FF01 和 FFE0/FFE1；DD A5 03/04/05 普通读取优先。需要登录时，只用用户已有六字符密码，可选真实 MAC 支持旧挑战流程。拒绝登录后停止自动重试，用户修改信息或切换板型后再试。 |
| 亚迪 FD/F403 | Nordic UART ASCII 十六进制分块 60/59/5，整页 CRC/长度成立后显示总压、SOC、单体和循环；容量/电流争议字段不推算。型号与倍率待真机复核。 |
| 明唐 FA00/E1 | 服务内按属性选取写/通知候选，只发 stateread；E1 TLV 按结构、字段长度和数值检查，无已确认 CRC。总压 0.01V/count 沿用参考实现，倍率仍待实物验证。 |
| 小哈锂电 | 仅完整 HBB<数字>SOC<三位数字> 名称广播电量；不连接未知 GATT，不估算总压/容量。持续广播依赖前台扫描，iOS 后台不保证更新，过期读数会清空。 |

maibms 表格里的「蓝宝」为电量计，本实现沿用这一分类。按用户要求移除原先仅识别品牌的三项，Build 34 时板型列表保留八项；Build 45 按用户要求新增陆行电量计，见 [接入范围与验证](luxing-meter-build45.md)。此前移除的三项仍不恢复。

## 使用

电池与 BMS → 开启读取 → 连接设备。列表会显示品牌提示；通用串口设备没有可靠品牌提示时必须手选。进入「板型与支持范围」可修正板型、查看限制；JBD/蓝宝可设置自己的模块密码/匹配码，仅保存在按设备隔离的 Keychain，不打印或导出。

旧 ANT UUID、名称和开关沿用；旧预设缺少板型时按设备已存板型恢复，之前从未保存板型的历史设备默认 ANT。新车辆预设保存 bmsFamily，切换板型会拆分正在记录的会话。未知新设备不会自动使用 ANT。已移除或无效的旧板型选择会解除设备选择，要求重新选择设备与板型，不会回退成 ANT 自动连接；已有记录保留。

通知订阅成功不算数据连接。候选通道必须收到对应协议的有效实时帧；无回应时回退下一个候选。发送端再次验证只读白名单，每条请求串行发送，支持 BLE 分片和背压。接收缓冲有上限，校验失败不更新读数新鲜度；仅设备信息或单体辅助块不会复活过期总压。亚迪与彦阳的 Modbus 类应答没有事务号/地址，长度匹配、单在途和失败排空只能降低同长度迟到帧错归属风险，不能消除线协议本身限制。

缺失字段通过 available 标记和可选统计处理；卡片显示 --，缺失电流/功率的峰值不写成零。真实 0% / 0A 保留。卡片品牌名随当前读数更新，统计和导出继续使用原有流程。

## 验证

`Tools/test_bms.sh` 包含原 ANT、卡片、记录统计以及多品牌测试。新增用例包括固定请求向量、发送白名单、CRC/校验和、字节分片、噪声上限、超时/排空、板型弱证据、JBD 自有密码登录、JK02/JK04/彦阳 B 参考报文、旧 A/蓝宝/亚迪/明唐合成报文及缺失字段统计。参考设备信息仅保留型号/版本，密码区域清零；合成样本不当作实物验证。

真实新板和手机 BLE 联调仍未完成。解析测试和 iOS 编译不能证明所有品牌/固件均可连接；原 ANT 设备已有用户实际读取基础，其余应分别真机确认电压、电流方向、温度、容量及长期刷新。按用户要求不使用 iOS 模拟器。

Build 33 历史验证（移除三项之前）：功能提交 `00343487066880f42190e9edee7433d1b72c16ab`，构建 https://github.com/Boos4721/CarWithin/actions/runs/45605156875 成功。BMS 专项 44 项全部通过（含 18 项新增多品牌测试）；完整核心 128 项，126 项通过、2 项因云端无本地 MFi 材料跳过，0 失败。车辆预设迁移、极核/台铃集成和 5 项 MFi 打包回归通过。generic iOS / iphoneos arm64 Release 编译成功，未运行 iOS 模拟器。真实身份在本地加入并通过证书/私钥、证书链、ECDSA 和 IPA 完整性检查。
