# Build 26：官方投屏助手观察版

## 已完成范围

配套观察 dylib、IPA 准备工具、CarWithin 助手页和手动报告导入。仅为下一步自动激活提供诊断，不实现自动激活和视频交接。用户目标九号出行 6.10.13，iPhone iOS 18.7.1，另有 iPadOS 16.6。没有提供对应 IPA，尚未在该版本或实车上验证 Hook。

## 离线和编译验证

- 原有完整核心测试，新增诊断 JSON 的 schema、来源、字段边界、大小、旧观察点未匹配和证据含义检查。
- Python 构造 Mach-O/IPA，验证新增 dylib 命令不移动原数据，拒绝加密、非空头部空间、重复注入、覆盖输入和输出。保持 Bundle ID、原 URL Scheme 与资源。
- iPhone/iPad Release 编译，独立插件使用 iOS SDK 编译 thin arm64，-Wall -Wextra -Werror。不运行模拟器。
- 打包输出含独立 dylib 与准备工具；官方九号 IPA、账户凭据和签名材料不上传。

## 实车检查

先验证修改版官方登录与连车；若不能正常使用，不进入后续流程。手动启停官方投屏并导出助手 JSON，观察点不匹配应明确显示，不调用不存在的方法。

CarWithin 在五寸、七寸连接设置中显示助手页。打开专用 URL 失败时提示未安装修改版，也可手动启动。运行 CarPlay 期间拒绝从助手页启动官方 App，避免两个发送端争抢端口。

报告仅手动导入，限制 128 KB/80 事件；导入失败不覆盖已有报告。预览重新编码已知字段，额外字段不转存。录制调用和非空视频转换不能当作仪表激活成功，只有用户现场标记出画作为人工证据。

打开报告不执行任何选择器、车辆指令或自动连接。退出九号后进程内采集可能丢失，需及时导出。五寸、七寸分别采集并说明实际车型/固件。
