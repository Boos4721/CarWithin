# Build 31 / MFi 身份加载与本地打包修复

截图中的「需要导入 MFi 身份」只说明没有成功加载身份，不能仅凭截图区分资源缺失、Keychain 不可见或材料校验失败。云端源码构建不包含本地身份文件；对这种 IPA 重新签名不能补齐 MFi 身份。

## 修改

- Keychain 优先；失败时记录错误并检查内置资源，兼容应用资源根目录与 BundledIdentity 子目录。只读取同一目录的完整三件套，不跨目录拼接。
- 内置身份先做证书与私钥匹配、ECDSA 签名自检，再尝试存入 Keychain。Keychain 保存失败会单独记录，已验证的内存身份仍可供本次会话使用。
- 新增 Tools/package_identity.py，在本机验证原有身份的 P-256 公私钥匹配、叶证书、PKCS7 链成员和 ECDSA 签名，再补入未签名 IPA。保留原编译文件内容和权限，检查 ZIP CRC 与三个资源；拒绝覆盖文件、不同身份或已签名安装包。
- 云端 INSTALL.txt 明确标注普通 CI IPA 不含身份。身份材料仍保留在本机，不提交到源码或 CI。

## 验证

核心测试新增资源根目录、子目录、部分资源、超限、空文件和符号链接检查。本地打包回归使用临时生成的测试证书和私钥，覆盖完整打包、原文件保留、缺失/不匹配材料、已有输出、不同身份、重复主应用和已签名 IPA。真实身份只在本机打包时验证。

继续执行现有协议与仪表集成检查，编译 generic iOS / iphoneos Release。按要求不运行 iOS 模拟器。编译与本地自检不能代替真机 iAP2 / MFi 认证，应在安装后查看内置或 Keychain 身份的载入日志并启动验证。
