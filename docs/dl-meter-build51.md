# 电岭计量器 DL 本地只读接入 / Build 51

开发分支新增 `dl` 协议族，设置中显示“电岭计量器”。参考固定版本及证据范围见 [协议核对](dl-meter-protocol-research.md)。新增接入不代表已经完成电岭所有型号实测。

- 扫描识别 `DL-BMS` 名称或完整 `0x6C64 + kjmk` 厂商标记；FFE0 服务本身不能确认 DL。沿用用户明确选择、收到有效实时数据后确认保存的流程。
- 使用 FFE0 / FFE1 写 / FFE2 通知。每次连接或候选通道重建时生成新的 secp256k1 临时密钥；本地 FC00 握手后，使用 AES-128-CBC 零填充通信。
- 只有 FC00 会话准备和 FC17 数据读取。发送边界验证本会话生成的完整请求；加密读取不会通过通用静态白名单。无参数写入、校准、MOS 开关或密码修改。
- 单请求在途，3 秒超时重新请求；有效实时帧后 1 秒再次轮询。超时和断连沿用现有候选通道切换及重连；收到握手回复本身不确认实时数据连接。
- 响应校验功能码、请求序号、单包计数、长度、累加和与加密零填充。密文最大 160 字节，通知输入按 4096 字节限制，支持分片、连续帧与重放拒绝。诊断不输出临时私钥或共享密钥。
- FC17 完整／精简布局：总压、电流、功率、SOC、额定与剩余容量、最多 32 串及 9 路温度。保留正放负充，明确映射状态。完整布局提供循环容量、循环次数和设备报告压差；精简布局仅从有效单体计算压差，不虚构循环值。
- 无效或缺失字段保持可选，未接单体保留串号空位，不把未知 MOS 状态当成告警或 MOS 温度。支持协议中的旧固件单体换算规则，但具体硬件倍率仍需对照实测。
- 复用现有电池详情、卡片、单体、统计、历史和 CSV，以及手机／九号 4.3、5、7 寸／极核的 BMS 叠加管线。
- 协议移植遵循 NinebotEnhance Apache-2.0；椭圆曲线运算使用固定 micro-ecc v1.1 BSD-2-Clause。原始许可与修改说明随 App 打包。

新增 16 项 Swift 测试覆盖 SEC2 曲线向量、ECDH 对等结果与错误点、NIST AES-CBC 已知向量、发送白名单、两种数据布局、字段缺失、符号、状态、全部 161 个密文切分点、串号／功能码／分包计数／校验／填充拒绝、重复、超时与有界噪声恢复。另在 Linux 本机将生产 C 椭圆曲线桥与 Python cryptography 独立实现做了 32 组随机公钥及 ECDH 对照，全部一致。

原生 macOS 测试及 generic iOS arm64 Release 结果以本次 Actions 为准，不增加模拟器。DL 硬件 BLE、充放电对照及仪表实际显示仍需用户实测。
