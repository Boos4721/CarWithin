# 自动推荐、字段能力与记录完整度 / Build 36

## 名称

界面板型统一为蚂蚁保护板、彦阳保护板、极空保护板、嘉佰达保护板、亚迪保护板、明唐保护板。蓝宝电量计和小哈广播电量保留实际类别。卡片短名使用中文品牌；协议详情单列，持久化 rawValue 与 BLE 识别规则保持稳定。

## 显示与字段

新增自动推荐 / 自定义。全新配置默认自动推荐；已有字段偏好和缺少新字段的旧车辆配置继续自定义，保留原顺序。模式随车辆配置保存。自动模式最多四项，优先电量、总压、电流、温度，再取压差和功率；只从有效读取过的字段中选择。首次等待使用板型基础布局。字段在同一设备和协议变体内累积，短时缺失不缩减布局；JK02/JK04 或彦阳 B/旧 A 变体切换清理先前证据。自定义布局始终独立保存。

字段能力页面与开关说明区分：当前可读取、曾提供但暂未读到、等待确认、当前协议未提供。JK04、彦阳旧 A、亚迪和小哈按当前接入协议标明明确缺失字段；其他字段缺失保持未知。压差说明区分设备报告和按逐串计算。自动推荐不会从电量或电压估算不存在的字段。布局示例仅用于设置，不进入实时数据或统计。

## 完整度定义

新记录以单调时钟保存记录总时长，有效覆盖率 = 原有连续有效采样时长 / 记录总时长。初次等待降低覆盖率，但不记为数据中断。最后一帧超过共同的五秒有效期后计一次中断，时长从过期时起算；反复计时不会重复计数。新帧返回时关闭该中断，后台缺少中间回调也能在恢复时识别间隔。不中断记录自身，不猜测蓝牙/系统/设备造成失联的原因。

手动或自动结束时冻结完整度；旧统计没有 coverage 字段则提示未保存，不从历史曲线重建。新信息进入统计与完整记录 JSON，电压 CSV 仍仅导出原有趋势窗口。没有有效样本时不生成历史记录。

## 验证与范围

新增推荐/字段/中文名称测试与完整度边界测试，覆盖真实零值、稀疏帧、断开后布局稳定、协议变体变化、手动偏好独立、首次等待、五秒有效期、后台间隔、时钟倒退、结束冻结及旧 JSON 兼容。车辆预设迁移检查增加模式往返测试。按用户要求不使用 iOS 模拟器，运行核心测试并编译 generic iphoneos arm64 Release。

实际卡片可读性、不同品牌与手机的长时间数据刷新仍待实物验证。电池档案、多指标趋势、提醒和 Wh 统计属于后续工作。
