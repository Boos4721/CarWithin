# 多品牌 BMS 连接与详情体验 / Build 35

## 本次范围

- 电池首页以当前设备、板型、结构化连接状态和实时读数为首屏；详情、显示设置、记录和设备管理四个入口。
- 蓝牙连接、服务发现、订阅、首批有效帧、实时数据、过期、重连、登录/板型/权限问题分别处理；首页提供对应处理入口和更新时间。
- 设备管理将扫描到的已保存设备优先分组，沿用用户确认的板型；名称和服务推测不覆盖已存板型。
- 首次添加经过设备选择、板型确认、首批读数核对、保存。核对中的选择仅在内存中；收到有效数据才可保存。车辆配置仅引用已保存的选择，核对数据不写入骑行记录。
- 返回、取消或关闭设置时撤销待确认选择并恢复已保存设备。关闭 BMS 时也撤销待确认选择；模块登录信息由用户明确保存，仍按设备 UUID 保存在 Keychain。
- 单体网格保留原串号和缺失槽位，最高/最低同时有文字和颜色提示。缺失、无穷和非法电压不参与极值。至少两串有效电压才计算逐串压差；单槽与汇总压差不混淆。无逐串数据时说明，数据过期清空。
- 原生动态字体、VoiceOver 字段描述、按钮最小 44pt；大辅助字号单列网格，普通字号按手机/iPad 可用宽度使用三/四列。

## 检查

BMSExperienceTests 覆盖订阅与数据连接区分、过期/恢复入口、广播来源、已存板型优先、缺失槽位、异常值与极值及 64 串上限。原有 BMS 协议、统计和车辆配置检查继续运行。

iOS 真机目标 Release 编译和测试由开发分支 Actions 执行；按用户要求不运行 iOS 模拟器。实际车载 BLE、首次连接流程、动态字体布局及后台恢复还需要 iPhone/iPad 与电池确认，编译和解析测试不替代实物验证。

## 后续

按板型推荐卡片、独立电池昵称/档案、多指标趋势、数据完整度、阈值提醒和 Wh 统计仍为后续计划，本次未实现。
