# Build 25 验收

## Wi-Fi 简化与读取

- 主页面只保留一个「读取当前 Wi-Fi」入口，同时请求当前 SSID 与本 App 对应 Keychain 密码。不能将 fetchCurrent 解释为系统密码读取接口。
- 同一 SSID 密码为空时每次均重试；已输入内容不被同网读取覆盖。切换 SSID 时清理上一网络密码。
- 从系统设置首次复制并粘贴后，保存并加入或返回保存；再次进入并点击读取，密码应恢复。签名访问组变更、锁定或没有已存项时给出准确状态。
- 明确读取中/无权限/无当前网络/密码缺失；不保存固定候选密码。密码显示离页后复位隐藏。
- 更多选项默认折叠，可配置开放网络与兼容信道。根据 fetchCurrent 提供的 securityType 核对开放网络，unknown 不推断为开放；旧开放配置不能覆盖当前加密网络。
- 查看首次密码帮助后留在编辑页，不触发失焦保存或丢失已有输入；密码帮助遵循 iOS 的设置 Wi-Fi 查看与复制流程。

## BMS 历史与导出

- 按车辆、今天/最近 7 天/最近 30 天、记录中/已结束/已保存片段组合筛选；时间按本地日历日期，7 天包含今天和此前 6 天。
- 空列表显示相应提示，筛选不删除记录。活动记录不可左滑删除，旧记录删除仍二次确认。
- 新记录车辆 UUID 与蓝牙设备 UUID 可选，旧版 JSON 缺少这些字段可解码。车辆改名后按 UUID 匹配，同名但不同 UUID 不混入；旧数据仅按名称回退。
- 活动详情每次有效数据更新摘要和趋势，不停留在进入页面的旧快照。导出在预览打开时取完整快照，预览内容与分享文件一致。
- CSV 使用英文列名、明确秒与伏单位、固定小数点和 CRLF；包含区间最低/最高/最新电压及断线分段标记。旧抽样的区间极值留空，sample_kind 为 legacy_sample。
- CSV 仅导出最近最多 120 个已保留区间，预览中明确范围限制；JSON 全程统计保留原来的全程极值。
- 曲线支持轻点与水平滑动选点，竖向滑动仍滚动列表。VoiceOver 上下轻扫切换区间，旧记录不朗读不存在的区间极值。
