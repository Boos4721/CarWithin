# Build 24 验收

## 电压记录修复

用户提供的记录摘要最低 83.67 V，图表最低却为 85.06 V。旧实现逐帧统计全程极值，但曲线每五秒只保存一帧，中间的短暂压降会丢失。

新记录为每个五秒区间保存最低、最高和最新电压，并保存区间内最后样本的时间。蓝线表示区间最新电压，竖条表示该区间的电压范围；摘要「全程电压」与可见曲线窗口分别标明。最多保留最近 120 个区间，全程统计不受窗口裁剪影响。

- 同一五秒内先收到 86.93 V，再收到 83.67 V，最后回到 85.06 V：该区间必须保留 83.67–86.93 V，最新值为 85.06 V。
- 不满五秒即停止/保存片段，最后收到的样本必须出现在区间中；不能等待下一次抽样才保存。
- 重复、过期、时间倒退仍不计入；中断超过五秒后新段不连接旧段。
- 旧版 JSON 中没有区间极值/结束时间字段，仍可读取。图中注明「旧版抽样」，不能将全程最小值随意插入某个历史时刻。
- 连续运行超过十分钟，图表显示保留窗口，摘要包含全程；二者范围可能不同，不能把窗口范围标为全程。

## 电池与 BMS 界面

- 首页显示连接状态与六项读数；未连接或超过五秒无有效数据时六项均为 --。
- 「连接设备」扫描、手选 ANT、记住和重连按原流程；关闭读取后提供明确的开启入口。不要按最强信号自动切换设备。
- 「电池详情」可查看容量、串数、温度和状态。新首页不需要常驻扫描列表或原始状态位。
- 卡片拖动排序后立即同步手机和五寸/七寸，重开保留。开关其他字段不打乱已有顺序，至少保留一项。
- 左上、右上、左下、右下分别检查。旧值 0/1 仍表示右上/右下。背景三档改变黑色背景透明度，文字可读，告警仍保留。
- 设置中无实时读数时明确显示示例预览，实际卡片仍显示等待/失联；示例不得计入统计或仪表视频。
- 修改卡片不重启 BLE、不重开手动结束的记录。车辆配置保存字段顺序/位置/背景，旧车辆缺少背景字段时保留标准背景。

## Wi-Fi

- 不再出现「填入九号候选密码」按钮或固定密码注入逻辑。
- 当前 SSID 已存在且密码为空时，再次点读取当前网络，仍尝试从本 App Keychain 取密码；失败后可重新读取，不缓存为成功。
- 没有本 App 保存的密码时明确提示，不宣称读取到系统密码。支持系统粘贴按钮与临时显示；退出编辑页恢复隐藏。
- 已经输入的密码不能被自动读取覆盖；SSID 切换时仍清理上一网络的密码，按新 SSID 读取。
- 相同签名/访问组的覆盖安装后检查已有配置。重新签名导致访问组变更时，不保证能读取另一个安装实例的 Keychain，需重新保存。

## 自动验证与限制

核心测试覆盖区间压降、最后样本、断线分段、旧记录解码、排序与配置恢复。本轮按用户要求不运行模拟器，只执行核心测试、车辆配置兼容性检查和 iPhone/iPad Release 编译。界面效果通过真机安装验收。

核心测试与编译不能代替五寸/七寸仪表、蓝牙、签名 Keychain 与 Wi-Fi 权限的真机验证。本次仍未实现九号出行的独立投屏激活流程。

## 首次配置与恢复操作

- 新安装、没有 SSID 的 iPhone 首次打开进入配置检查；只自动展示一次。已有所选预设和有效凭据的升级用户不强制引导。
- 指南按顺序进入输出/Wi-Fi/BMS，BMS 可跳过。完成按钮校验 Wi-Fi 与身份；可选择完成后立即启动或稍后连接。
- 连接或等待网络期间不可从指南修改配置，提供状态与报告入口。取消指南后可从设置重开。
- 设置分组能进入原有连接、车辆配置、显示、声音、后台、画中画、诊断、版本与支持入口；设置列表中仍无 CarPlay 身份项。
- 默认 Wi-Fi 编辑页不清空当前预设；新增网络通过预设页添加。开启密码显示后离开页应重新隐藏。
- 启动失败和 Wi-Fi 配置错误后显示重试与恢复按钮；停止不会把失败报告覆盖为成功。重试新建时间线，手动停止清除失败状态。返回前台或关闭设置不能把错误覆盖成「准备就绪」。
- 点选新记录曲线，显示该区间最低/最高/最新值和区间时间；旧记录只显示它保留的抽样值。点选不会改变历史或统计。
